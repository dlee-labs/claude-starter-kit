# Personal files schema

Two files in `CONTEXT/`, both local, never committed, never synced, never overwritten by an update.

## my-profile.md

```markdown
# Profile

**Owner:** <name>
**Created:** YYYY-MM-DD
**Onboarding state:** folder [x] · rules [x] · tour [ ] · interview [ ] · first-project [ ] · handoff [ ]

## Role
<their words>

## Rhythms
<week, month, school year>

## Outputs
<real artifacts>

## Time sinks
<two or three specifics>

## Capability snapshot (YYYY-MM-DD)
| Check | Result |
|---|---|
```

## my-preferences.md

Created the first time a standing preference is confirmed. One line per preference, in the person's own
words, with the date. A new preference that contradicts an old line: quote the old one and ask which wins.

```markdown
# Preferences

- 2026-11-06: "Lead with the risk, then the fix."
```

Never Restricted material in either file.
